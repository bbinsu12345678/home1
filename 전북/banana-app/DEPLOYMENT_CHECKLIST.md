## 🚀 배포 프로세스

### Netlify 배포 방법

#### 옵션 1: Git 연동 (권장)
1. GitHub/GitLab에 코드 푸시
2. Netlify 대시보드에서 "Import from Git" 선택
3. Repository 연결
4. 자동 배포 설정

#### 옵션 2: 수동 배포
1. 빌드 실행: `npm run build`
2. `out` 폴더를 ZIP으로 압축
3. Netlify Drop에 드래그 앤 드롭
4. 도메인 설정

### 배포 후 즉시 해야 할 일

1. **사이트 접속 테스트**
   - 메인 페이지 로딩 확인
   - 여러 지역 페이지 테스트 (/1, /100, /1000 등)
   - About 페이지 확인
   - 이미지 로딩 확인

2. **구글 서치콘솔 등록**
   - 소유권 인증
   - 인증 코드로 파일 수정
   - 사이트맵 제출

3. **네이버 서치어드바이저**
   - 웹페이지 수집 요청
   - 주요 페이지 10개씩 제출

4. **성능 테스트**
   - PageSpeed Insights 실행
   - 모바일 친화성 테스트
