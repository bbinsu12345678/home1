## 적용 내용

1. 비존재 동적 페이지 처리 수정
- `notFound()`를 사용하도록 변경
- 잘못된 `200 OK + Page not found` 흐름 제거

2. 예약 경로 제외
- 페이지 ID 생성과 sitemap 생성에서 `404`, `500` 제외

3. URL 신호 통일
- 상세 페이지 canonical과 JSON-LD URL을 `SITE_URL` 기반으로 통일
- 상세 페이지 URL trailing slash 기준으로 통일

4. 페이지네이션 보정
- 실제 존재하는 페이지 ID 목록 기준으로 이동하도록 변경
- 예약 ID가 링크에 노출되지 않게 정리

5. 404 canonical 정리
- 전역 layout canonical 제거
- 홈 canonical만 홈 페이지에서 유지
