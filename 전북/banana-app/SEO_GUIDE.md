## 🚀 구글 서치콘솔 등록 방법

### 1단계: 구글 서치콘솔 접속
1. https://search.google.com/search-console 접속
2. Google 계정으로 로그인

### 2단계: 속성 추가
1. "속성 추가" 클릭
2. URL 접두어 선택
3. `https://bananajeonju.netlify.app` 입력

### 3단계: 소유권 확인
1. HTML 태그 방법 선택
2. 제공된 메타태그 복사 (예: `<meta name="google-site-verification" content="XXXXX" />`)
3. `src/app/page.tsx` 파일의 53번째 줄 수정:
   ```typescript
   "google-site-verification": "YOUR_GOOGLE_VERIFICATION_CODE", // 실제 코드로 교체
   ```
4. 실제 인증 코드로 교체 후 배포
5. 구글 서치콘솔에서 "확인" 클릭

### 4단계: 사이트맵 제출
1. 왼쪽 메뉴 → "Sitemaps" 클릭
2. `sitemap.xml` 입력
3. "제출" 클릭

### 5단계: 색인 요청
1. URL 검사 도구 사용
2. 주요 페이지 URL 입력
3. "색인 생성 요청" 클릭

## 📱 네이버 서치어드바이저 추가 설정

### 이미 완료된 사항
- 사이트 등록 ✅
- 소유권 확인 ✅ (인증코드: 2c62c3736...)
- robots.txt 설정 ✅

### 추가 권장 작업
1. **RSS 제출**
   - 서치어드바이저 → 요청 → RSS 제출
   - RSS 피드 URL 입력

2. **웹페이지 수집 요청**
   - 요청 → 웹페이지 수집
   - 주요 페이지 URL 제출 (하루 10개 제한)

3. **사이트맵 재제출**
   - 요청 → 사이트맵 제출
   - `https://bananajeonju.netlify.app/sitemap.xml`
